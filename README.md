# Proyecto1-Compi2-SS26
Primer proyecto del curso de Compiladores 2 - Universidad de San Carlos de Guatemala - CUNOC- Consiste en hacer un compilador que permita validar 3 lenguajes alto nivel ('Y?', 'Zetario' y 'PigLatin'), si el programa de entrada es valido entonces se traduce a Codigo 3 Direcciones - Tecnologias utilizadas: JDK 25 y ANTLR 4
